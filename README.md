# 外贸单证系统

面向外贸业务员与单证员的浏览器端制单工具。公司、客户和商品资料可重复用于报价单、形式发票、商业发票、装箱单和销售合同，也可用于 AMS、ISF、VGM、SI 船运资料单；结构化表单与 A4 预览联动，并在本地生成可选择文字的 PDF。

## 功能

- 三步新建九类单证，编辑器内切换类型时按目标单证保留共同资料。
- 公司、客户、商品和历史单证快照分离，修改资料库不会改写历史单证。
- AMS、ISF、VGM、SI 提供独立的相关方、船运、货物、集装箱和签署字段；VGM 支持两种核实总重方法。
- AMS 和 ISF 仅生成申报资料准备稿，不执行电子申报，也不生成海关或承运人回执。
- 产品库支持 Excel／CSV 导入、Excel 导出和字段样例下载；提供逐行校验、重复 SKU 跳过或覆盖。
- 九类单证模板支持预览、编辑、JSON 模板包导入导出，并应用于之后新建的单证。
- 模板编辑采用设置与 A4 示例并排工作区，实时联动语言、配色、条款和显示规则；手机端提供设置／预览页签。
- 11 种单据语言、9 款纸张配色、多页装箱单、中英阿混排和阿拉伯语 RTL。
- 浏览器本地保存，无账号、云同步、在线发送、电子签约或多人协作。

## 本地运行

```bash
npm install
npm run dev
```

## 检查与构建

```bash
npm run lint
npm run build
npm run preview
```

生产文件输出到 `dist/`。`vite.config.ts` 使用 `base: './'`，构建结果可部署到 GitHub Pages 的仓库子路径；仍需要在 GitHub 仓库中自行配置 Pages 的发布来源。

## 本地数据与备份

资料保存在当前浏览器的 `localStorage` 中，不会上传到服务器，也不会自动同步到其他浏览器或设备。清除浏览器数据前，请导出产品和模板，并下载需要保留的 PDF；当前没有历史单证整包备份功能。

产品导入支持 `.xlsx`、`.xls` 和 UTF-8 `.csv`，单次最多 2000 行，必需表头为 `SKU`、`英文产品名称`、`默认单位`、`默认单价`。表格不包含产品图片。覆盖重复 SKU 时保留原产品 ID 和图片，历史单证快照不变。

模板包是系统专用 JSON 文件，可包含一类至九类模板，只携带版式、默认条款、默认船运信息和显示规则，不包含公司、客户、商品、图片或历史单证。现有 Word／PDF 不会自动转换为可编辑模板。

电子印章仅作为单证图像，不等同于法律电子签名。演示客户、商品和交易均为虚构示例。默认公司资料仅预置 QOSA 名称与 Logo，地址、联系方式和银行信息需由使用者填写；QOSA Logo 来源于使用者的 QOSA 周报项目，并保留原始标识造型。
